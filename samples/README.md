# Туршилтын материал («AI custom»)

Энд байгаа бүх компани, үнэ, хаяг, утасны дугаар **зохиомол**. Жинхэнэ байгууллагын мэдээлэл биш.

Аппын «AI custom» дэлгэцэд (`CoachCustomView`) файлыг оруулахад материалаас AI дасгалжуулагч үүснэ. Апп байхгүй бол нэвтэрсэн хэрэглэгчээр `POST /api/coach/packs` руу файлын агуулгыг `notes`-оор (эсвэл `files`-аар, `text/plain`) илгээж болно — оролтын бүтэц `CreatePackInputSchema` (`src/lib/coach/engine.ts`). Үүссэн дүрийг `/coach?pack=<id>` дээр туршина.

| Файл | Салбар | Дүр (`persona`) | Юуг шалгах |
|---|---|---|---|
| `auto-dealer.txt` | Авто худалдаа | `buyer` | Үнэ, зээлийн нөхцөл, trade-in, ажилтан үнэ хямдруулах эрхгүй |
| `hotel-front-desk.txt` | Зочид буудал | `customer` эсвэл `caller` | Цуцлалтын 48 цаг, эрт орох / орой гарах үнэ, зочны өрөөний дугаар хэлэхгүй |

## Яаж шалгах
1. Файлыг оруулж, дүр үүсэхийг хүлээнэ.
2. Үүссэн баримтуудыг (facts) материалтай тулгана: **материалд байхгүй үнэ, нөхцөл гарвал алдаа.**
3. Ажилтны дүрд ярьж үзээд санаатайгаар буруу хариулт өгнө (жишээ нь «24 цагийн өмнө цуцалбал үнэгүй»). Дүгнэлтийн `factErrors`-д гарах ёстой.
